# 🌶️ Délicea

Landing Page officielle de Délicea.

## 📌 Description

Délicea est une page de vente moderne dédiée aux packs d'épices de haute qualité.

## ✨ Fonctionnalités

- Landing page en arabe
- Design responsive (mobile et PC)
- Présentation des packs
- Sélection des offres
- Formulaire de commande
- Bouton WhatsApp
- Animations modernes

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
